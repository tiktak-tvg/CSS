### Основные CSS-свойства.

``color`` - Определяет цвет текста элемента [Таблица цветов в HTML](https://colorscheme.ru/html-colors.html)

``background-color`` - Определяет фоновый цвет элемента

``background-image`` - Определяет фоновое изображение элемента

``font-size`` - Устанавливает размер шрифта 

``font-style`` - Устанавливает стиль начертания шрифта - обычное, курсивное или наклонное

``font-family`` - Задает семейство шрифта, которое будет использоваться для оформления текста содержимого

``text-align`` - Устанавливает горизонтальное выравнивание текста элемента

``text-transform`` - Управляет преобразованием текста элемента в заглавные или прописные символы

``border-color`` - Цвет границы. Определяет цвет всех четырех сторон рамки HTML элемента

``border-radius`` - Устанавливает радиус скругления углов рамки

``margin`` - Устанавливает внешний отступ

``padding`` - Устанавливает внутренний отступ

``display`` - Определяет, как элемент должен быть показан в документе

### Селектор Элементов CSS.

Селектор типа или селектор элементов указывает, к каким элементам должно применяться правило, путем присвоения имени типу элемента, например ``<h1>``. 
Другими словами, селектор элементов выбирает элементы HTML на основе имени элемента.

```
h1 {
	text-align: center;
	color: DarkRed;
}
В HTML будет запись такая
<h1>Aspose.HTML for .NET</h1>
```

ID Селектор.

Селектор ID выбирает определенный элемент, используя атрибут id элемента HTML. Элемент будет выбран, если его атрибут id точно соответствует значению, указанному в селекторе ID.

```
#demo {
  	background-color: #fcded4;
	font-size: 24pt;
}
В HTML будет запись такая
<p id="demo">У этого абзаца есть специальный идентификатор ID!</p>
```

#### Class Селектор.

Селектор классов сопоставляет HTML-элементы с определенным атрибутом class.<br> 
Вы можете использовать атрибут class для всех элементов HTML, допустимых в разделе body документа HTML, включая сам элемент <body>. <br>
Чтобы выбрать элементы с определенным классом, напишите символ точки (.), а затем имя класса.<br> 
Например, если мы хотим, чтобы все элементы с классом «main» имели разные цвет фона, цвет текста и размер шрифта, мы должны использовать следующее правило CSS<br>
```
.main {
	background-color: #d4e9fc;
	color: red;
    font-size: 16pt;
}
В HTML будет запись такая
<p class="main">Точка (.) используется для обозначения атрибута класса для создания селектора CSS-класса</p>
```

### Семантика HTML5.

``<article>`` - Определяет независимый, самодостаточный контент. Например: публикация на форуме; публикация в блоге; газетная статья<br>
``<aside>`` - Элемент определяет некий контент, находящийся в стороне от контента, внутри которого он расположен (как боковой блок страницы, "сайдбар")<br>
``<header>`` - Предназначен для определения заголовочного блока или "шапки" документа или раздела. Элемент следует использовать как контейнер для вводной информации<br>
``<main>`` - Определяет основной контент документа<br>
``<figcaption>`` - Добавление визуального пояснения к изображению<br>
``<figure>`` - В HTML5 изображение и пояснение к нему может быть сгруппировано в элементе ``<figure>``<br>
``<footer>`` - предназначен для определения "подвала" документа или раздела. Обычно в "подвале" размещают информацию об авторе документа, ссылки на условия использования текста, информация об авторских правах, контактные данные и т.п.<br>
``<nav>`` - Элемент предназначен для основного блока навигационных ссылок<br>
``<section>`` - Определяет раздел в документе. "Раздел — это тематически сгруппированный контент, как правило с заголовком." Например,  вступление, основной контент и контактная информация<br>
``<time>`` - Определяет дату/время<br>                               

### Тег DIV.

Элемент ``<div>`` является блочным элементом (про блочные и строчные элементы мы поговорим на следующем шаге) и предназначен для выделения фрагмента документа с целью изменения вида содержимого. Как правило, вид блока управляется с помощью стилей.<br>
Элемент ``<div>`` распространен в разметке, в него можно вкладывать: изображения; текст; другой ``<div>`` и т.д.<br>

### Отступы.

``Внутренний отступ`` - расстояние от границы элемента (border) до содержимого этого элемента (например текста).

### Списки.


**Маркированный**

Список из неупорядоченных элементов.

> Состоит из двух тегов:

``<ul>`` - тег начала и конца списка. Тег парный

``<li>`` - пункт списка. Тег парный

 

**Нумерованный**

Упорядоченный список, каждый пункт имеет свой номер (число, букву и т.п.).

> Состоит из двух тегов:

``<ol>`` - тег начала и конца списка. Тег парный

``<li>``  - пункт списка. Тег парный

Создадим маркированный список<br>
```
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>PHP</li>
  <li>BITRIX</li>
</ul>
```
Создадим нумерованный список<br>
```
<ol>
<li>HTML</li>
<li>CSS</li>
<li>PHP</li>
<li>BITRIX</li>
</ol>
```

### Единицы измерения/

**Абсолютные величины**

Пиксель (px) – это самая базовая, абсолютная и окончательная единица измерения. Также пиксель является наименьшим элементом измерения матрицы дисплеев. 
> Например, 300px. 

**Относительные величины**

1em – единица измерения, определяющая текущий размер шрифта. Величина определяется по текущему контексту.<br> 
Так как значение в em высчитывается относительно текущего шрифта, то вложенная строка в 3 раза больше, чем первая. 
> Например,

```
<div style="font-size:24px">
  привет
  <div style="font-size:3em">мир</div>
</div>
```

проценты - относительная величина размера родителя

```
<div style="font-size:100%">
  привет
<div style="font-size:200%">мир</div>
</div>
```

rem - относительная величина размера шрифта.  1rem всегда будет равен значению font-size, которое было определено в html

```
<div style="font-size:2rem"> привет </div>
<div style="font-size:1rem">мир</div>
```

Размеры рядов и столбцов в гриде можно задавать не только в px, но и в единицах гибкости fr (фракция).<br> 
Использование этих единиц означает, что все пространство для размещения элементов будет разбито на одинаковые доли или фракции.<br> 
Каждый элемент сможет взять определенную часть этого разбиения.<br>

```
<div id="parent">
	<div>1</div>
	<div>2</div>
	<div>3</div>
	<div>4</div>
	<div>5</div>
	<div>6</div>
	<div>7</div>
	<div>8</div>
	<div>9</div>
</div>
#parent {
	display: grid;
	grid-template-columns: 1fr 1fr 3fr;
	border: 2px solid #696989;
	padding: 10px;
	width: 600px;
}
#parent > div {
	padding: 10px;
	border: 1px solid #696989;
	box-sizing: border-box;
	border: 1px solid #696989;
}
```

## Псевдоклассы и Псевдоэлементы.

Псевдоклассы определяют состояние уже существующих элементов, которое может меняться при определенных условиях.

Псевдоклассы — это ключевые слова, которые начинаются с двоеточия:

:pseudo-class-name

Псевдоэлементы – это селекторы, которые определяют область элементов, которая изначально отсутствует в дереве документа. Эта область создается искусственно с помощью CSS.

Ключевое отличие между ними в том, что псевдоклассы определяют именно состояние элементов, которые уже существуют на странице, а псевдоэлементы создают области (искусственные элементы), которых изначально на веб-странице не было.<br> 
Но и те и другие отсутствуют в исходном коде документа.

список псевдоэлементов:

E::first-line

E::first-letter

E::before

E::after

Здесь, E-  элемент, к которому применяется селектор.

> Пример.

```
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">
<html>
<head>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
<title>HTML структура документа</title>
<style>
	.main-menu ul li a:hover{
		color: yellow;
	}
	<!-- или обратится по классу -->
<!-- 	.item:hover{
		color: yellow;
	} -->
</style>
</head>
<body>
<header class = "header-site">
  <h1 class="top">Оглавление</h1>
  <nav class="main-menu">
     <ul>
        <li><a href="#" class="item">О нас</a></li>
        <li><a href="#" class="item">Контакты</a></li>
     </ul>
  </nav>
</header>
<a href="about.html">Ссылка на каритнку</a>
</body>
</html>
```
